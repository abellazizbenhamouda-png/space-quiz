# Orbit Quest

Orbit Quest is a space-themed quiz that runs entirely in your browser. Answer questions, learn a fact about each one, and see your score at the end.

## Run locally

No installation or build step is needed. Open `index.html` in a web browser.

## Deployment

The GitHub Actions workflow in `.github/workflows/pages.yml` publishes `index.html` to GitHub Pages when changes are pushed to `main`. Pull requests run the build and artifact-upload steps without deploying.
